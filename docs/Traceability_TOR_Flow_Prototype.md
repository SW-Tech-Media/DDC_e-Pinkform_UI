## วิธีอ่านเอกสาร

- **สถานะ** ใช้ 4 ค่า
  - **ครบ** — Prototype แสดงฟังก์ชัน / ฟิลด์ / พฤติกรรมตามข้อกำหนดได้ครบในระดับหน้าจอ
  - **บางส่วน** — มีหน้าจอแล้ว แต่ขาดฟิลด์ / ขั้นตอน / กรณียกเว้น หรือข้อมูลขัดกัน (ระบุในหมายเหตุ)
  - **ไม่มี** — ยังไม่มีหน้าจอหรือพฤติกรรมนี้
  - **N/A** — ไม่ต้องแสดงใน Prototype (เป็น infra / backend / เงื่อนไขสัญญา) — ระบุเหตุผลในหมายเหตุ
- รหัสหน้าจอใช้ตาม `src/router/screens.js` (P-xx / B-xx) — ดูตารางเทียบ route ในหัวข้อ 1
- "เสนอ" = ข้อเสนอเพิ่มเติมของทีม ไม่ใช่ข้อกำหนดใน TOR
- ข้อ TOR ที่ไม่ไฮไลท์ (คุณสมบัติผู้เสนอราคา งวดงาน ข้อ 10 รายงานส่งมอบ) ไม่นับใน Traceability นี้

## 4. รายการ Gap พร้อมข้อเสนอ

ระดับ: **สูง** = กระทบการสาธิต Flow หลักหรือข้อ TOR ที่ตรวจรับได้ชัด · **กลาง** = ขาดกรณียกเว้น / กฎย่อย · **ต่ำ** = ปรับปรุงคุณภาพ / ข้อเสนอ
